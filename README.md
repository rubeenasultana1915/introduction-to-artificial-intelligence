# Introduction to Artificial Intelligence

An undergraduate course introducing fundamental and modern concepts in Artificial Intelligence through conceptual learning, programming, experimentation, and project-based learning.

## Course Overview

This course introduces students to fundamental Artificial Intelligence concepts and techniques, including intelligent agents, search, knowledge representation, probabilistic reasoning, machine learning, neural networks, deep learning, Transformers, large language models, and responsible AI.

The course emphasizes learning through a combination of interactive lectures, low-stakes assessments, programming assignments, hands-on laboratories, collaborative learning activities, and a semester-long AI project.

## Learning Outcomes

By the end of the course, students should be able to:

1. Explain fundamental concepts and approaches in Artificial Intelligence.
2. Formulate problems using appropriate AI problem-solving techniques.
3. Implement and analyze classical search algorithms such as BFS, DFS, and A*.
4. Apply knowledge representation and probabilistic reasoning techniques.
5. Build and evaluate machine learning models using Python.
6. Explain fundamental concepts in neural networks and deep learning.
7. Describe the principles behind attention mechanisms and Transformer-based models.
8. Conduct AI experiments and interpret model performance and errors.
9. Discuss issues related to bias, fairness, explainability, privacy, and responsible AI.
10. Communicate AI solutions and experimental findings through technical reports and presentations.

## Teaching and Learning Approach

The course follows a cycle of:

**Concept → Example → Implementation → Experimentation → Reflection**

Students first develop conceptual understanding, then apply the concepts through programming and experimentation. Frequent low-stakes assessments provide feedback throughout the semester.

## Assessment Tools

Different tools are used according to the learning objective:

* **PrairieLearn** — low-stakes quizzes, randomized questions, algorithm tracing, and automated assessment
* **Perusall** — collaborative reading, annotation, and discussion
* **Jupyter Notebooks** — programming laboratories and experimentation
* **GitHub** — project development, version control, and documentation
* **Python / NumPy / Pandas** — computational activities
* **scikit-learn** — classical machine learning
* **PyTorch** — neural networks and deep learning
